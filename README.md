# artnet_sender
Art-Net送信用の簡易的なアプリケーション

## 起動
` uv run artnet_sender `  
## 使い方
### 接続
Target IP欄に送信先のIPアドレスを入力して`Apply`をクリック.  
ポートはArt-Net標準の6454です.  
ブロードキャストにはまだ対応していません. 
### フェーダの追加/設定
`+Add Fader`をクリックしてフェーダを追加.  
操作したいUniverse, Addressを入力して設定.  
Universeは0, Addressは1から始まります. 
### フェーダ操作
ツマミをドラッグ, もしくは下部の入力欄に直接値を入力. 
### フェーダ削除
下部のxボタンをクリック.  
フェーダを削除しても送信中の値は残ります.
